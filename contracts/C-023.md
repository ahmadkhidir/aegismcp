# C-023: GET /ready

**Status:** Frozen
**Owner:** services/gateway
**Auth:** None. The probe is served unauthenticated on the same listener as the agent transports, and its response exposes no tenant, credential, host, path, or exception detail.
**Request:** No query parameters and no body.
**Response 200:** Object with:
- `status`: string, exactly `UP`, only once startup has completed and every dependency check passes.
- `checks`: object whose members are exactly `configuration`, `policy`, and `auditLedger`; each member is an object with `status` exactly `UP`.
- `timestamp`: string, ISO-8601 date-time of the response.
**Response 503:** Object with:
- `status`: string, exactly `DOWN`, whenever the node must not receive agent traffic.
- `reason`: string, exactly one of `STARTING`, `CONFIGURATION_INVALID`, `POLICY_INVALID`, `LEDGER_UNWRITABLE`, or `SHUTTING_DOWN`. `STARTING` applies before startup completes, `SHUTTING_DOWN` once shutdown begins, and the remaining three name the first failed dependency check in the declaration order `configuration`, `policy`, `auditLedger`.
- `checks`: object whose members are exactly `configuration`, `policy`, and `auditLedger`; every check that failed carries `status` exactly `DOWN`, and every other check carries `status` exactly `UP`. A node that is still starting or already shutting down may report every check `UP`, because no dependency has failed.
- `timestamp`: string, ISO-8601 date-time of the response.
**Errors:**
- 405: The request method is not `GET`. The body is an object with `error` exactly `Method Not Allowed`, and no host, path, or exception detail.
- 500: The probe cannot be answered. The body is an object with `error` exactly `Internal Server Error`, and no host, path, or exception detail.

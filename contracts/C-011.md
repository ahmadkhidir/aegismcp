# C-011: POST /api/v1/compliance/export

**Status:** Draft
**Owner:** services/gateway
**Auth:** Compliance officer or administrator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `auditor` role.
**Request:** Object with:
- `framework`: string, required, one of `EU_AI_ACT`, `SOC2_TYPE2`.
- `format`: string, required, one of `JSON`, `CSV`, `PDF`.
- `agentId`: string, optional; when present the report covers only that agent identity.
- `from`: string, required, ISO-8601 date-time, inclusive start of the reporting period.
- `to`: string, required, ISO-8601 date-time, inclusive end of the reporting period.
**Response 200:** Object with `reportId` string, `framework` string, `format` string, `status` exactly `COMPLETED`, `generatedAt` ISO-8601 date-time, `recordCount` integer, `violationsCount` integer, `approvalsCount` integer, `merkleRoot` string, `signature` string holding the detached signature over the report digest, and `content` string. For `JSON` and `CSV`, `content` is the report text; for `PDF`, `content` is the Base64 encoding of the signed PDF archive.
**Response 202:** Object with `reportId` string and `status` exactly `GENERATING`. Returned when the requested range exceeds the synchronous generation ceiling; the finished archive is delivered through the configured email or webhook notification channel.
**Errors:**
- 400: `framework` or `format` is not one of the declared values, `from` or `to` is not an ISO-8601 date-time, or `from` is later than `to`.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds neither the `admin` nor the `auditor` role.
- 409: A hash-chain verification failure exists inside the requested range; generation is aborted and the body carries `brokenBlockIndex` for the first compromised block.

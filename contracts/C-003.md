# C-003: GET /api/v1/approvals/pending

**Status:** Draft
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `operator` role.
**Request:** Optional query parameter `limit`, integer from 1 to 100, default 50. The dashboard widget requests `limit=3`.
**Response 200:** Object with a `tickets` array, ordered by `expiresAt` ascending so the least remaining time-to-live appears first. Each ticket carries:
- `id`: string, the approval ticket identifier.
- `agentId`: string, the requesting agent identity.
- `toolName`: string, the target MCP tool.
- `argumentsPayload`: string, JSON-serialized request arguments with secret values already masked.
- `triggerPolicyId`: string, the policy rule that mandated human approval.
- `agentIntent`: string or null, the agent-supplied justification shown as the intent description; null when the call carried none.
- `status`: string, exactly `pending`.
- `createdAt`: string, ISO-8601 date-time.
- `expiresAt`: string, ISO-8601 date-time at which the ticket fails closed.
**Errors:**
- 400: `limit` is not an integer or falls outside 1 to 100.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator does not hold the `admin` or `operator` role.

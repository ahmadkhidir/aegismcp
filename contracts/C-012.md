# C-012: POST /api/v1/policies/simulate

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Security administrator or platform operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `operator` role.
**Request:** Object with:
- `agentId`: string, required, the agent identity to evaluate.
- `toolName`: string, required, the target MCP tool.
- `arguments`: object, required, the sample tool arguments; an empty object means no arguments.
**Response 200:** Object with:
- `verdict`: string, one of `ALLOWED`, `BLOCKED`, `REQUIRE_APPROVAL`.
- `ruleMatched`: string or null, the identifier of the rule that produced the verdict, or null when no rule matched and the fail-closed default applied.
- `violations`: array of strings, each an argument or schema constraint that the sample breached; empty when none.
Simulation evaluates the same compiled policy as live traffic and returns the verdict without dispatching the call upstream.
**Errors:**
- 400: The body is not a JSON object, `agentId` or `toolName` is missing, or `arguments` is not an object.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds neither the `admin` nor the `operator` role.

# C-015: GET /api/v1/audit/integrity

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Compliance auditor or administrator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `auditor` role.
**Request:** No query parameters and no body. The response reports the most recent completed chain verification.
**Response 200:** Object with:
- `valid`: boolean, true when the last completed verification found no hash-link mismatch.
- `totalVerifiedBlocks`: integer, the number of sealed blocks covered by that verification.
- `lastVerifiedAt`: string, ISO-8601 date-time of the last completed verification.
**Errors:**
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds neither the `admin` nor the `auditor` role.
- 503: The ledger store is unreachable, so the integrity state cannot be read.

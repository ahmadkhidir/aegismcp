# C-008: POST /api/v1/emergency/kill

**Status:** Draft
**Owner:** services/gateway
**Auth:** Console administrator or platform operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `operator` role. A `global` target additionally requires multi-factor re-confirmation before the request is accepted.
**Request:** Object with:
- `targetType`: string, required, one of `session`, `agent`, `server`, `global`.
- `targetId`: string, the session identifier, agent identity, or upstream MCP server identifier. Required for `session`, `agent`, and `server`; must be absent for `global`.
- `reason`: string, optional, recorded in the audit ledger with the administrative action.
**Response 200:** Object with `status` one of `QUARANTINED` for a session or agent target, `SEVERED` for a server target, or `LOCKDOWN` for a global target; `affectedSessions` integer counting the transport streams closed by the action; and `timestamp` ISO-8601 date-time. Every active stream for the target is closed before the response is returned, and subsequent connection attempts from a quarantined identity are refused.
**Errors:**
- 400: `targetType` is not one of the four declared values, `targetId` is missing for a scoped target, or `targetId` is supplied with `global`.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds neither the `admin` nor the `operator` role, or the `global` re-confirmation was not completed.
- 404: No session, agent identity, or upstream server matches `targetId`.
- 503: The kill signal could not be propagated to every peer gateway node within 500 milliseconds; the action is not acknowledged as complete.

# C-008: POST /api/v1/emergency/kill

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console administrator or platform operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `operator` role. A `global` target additionally requires a multi-factor re-confirmation of the initiating operator completed within the preceding five minutes, and in an Enterprise production deployment it also requires a distinct confirming second operator. The deployment identifies itself as an Enterprise production deployment through its configuration; the request carries no deployment or tier selector.
**Request:** Object with:
- `targetType`: string, required, one of `session`, `agent`, `server`, `global`.
- `targetId`: string, the session identifier, agent identity, or upstream MCP server identifier. Required for `session`, `agent`, and `server`; must be absent for `global`.
- `reason`: string, optional, recorded in the audit ledger with the administrative action.
- `secondApprover`: string, optional, the subject of a different `operator` or `admin` with an active authenticated session who has confirmed the action. Required on a `global` target in an Enterprise production deployment and permitted only there.
**Response 200:** Object with `status` one of `QUARANTINED` for a session or agent target, `SEVERED` for a server target, or `LOCKDOWN` for a global target; `affectedSessions` integer counting the transport streams closed by the action; and `timestamp` ISO-8601 date-time. Every active stream for the target is closed before the response is returned, and subsequent connection attempts from a quarantined identity are refused. The action is sealed in the shared ledger chain as an administrative audit entry (`action` `kill`) naming the initiating operator as `actor`, the supplied `secondApprover` or null, the target type and identifier or the global scope, the outcome, the operator's reason, and the seal timestamp.
**Errors:**
- 400: `targetType` is not one of the four declared values, `targetId` is missing for a scoped target, or `targetId` is supplied with `global`; an Enterprise production `global` request carries no `secondApprover` or carries a `secondApprover` identical to the initiating operator; or a `secondApprover` is supplied for anything other than an Enterprise production `global` target. No quarantine or lockdown is applied.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds neither the `admin` nor the `operator` role; the `global` multi-factor re-confirmation is absent or older than five minutes; or the supplied `secondApprover` does not resolve to an active authenticated operator session, holds neither `operator` nor `admin`, or has not confirmed the action. No quarantine or lockdown is applied.
- 404: No session, agent identity, or upstream server matches `targetId`.
- 503: The kill signal could not be propagated to every peer gateway node within 500 milliseconds; the action is not acknowledged as complete, and the nodes that applied it keep it in force.

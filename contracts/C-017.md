# C-017: GET /api/v1/policies/active

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin`, `operator`, or `auditor` role.
**Request:** No query parameters and no body.
**Response 200:** The active policy version as an object with `id` string, `name` string, `version` string, `rawYaml` string holding the complete declarative YAML, `status` exactly `active`, `gitCommitHash` string or null, and `createdAt` ISO-8601 date-time.
**Errors:**
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds none of the `admin`, `operator`, `auditor` roles.
- 404: No policy version is active yet, as on a fresh cluster with no policy loaded.

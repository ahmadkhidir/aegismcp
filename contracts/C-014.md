# C-014: POST /api/v1/approvals/{id}/reject

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `operator` role. The reviewer identity is taken from the verified token claims, never from the request body.
**Request:** Path parameter `id`, the approval ticket identifier. Body object with `reason` string, required and non-blank, the reviewer's rejection note delivered to the requesting agent and recorded in the ledger.
**Response 200:** Object with `ticketId` string, `status` exactly `rejected`, `reviewedBy` string holding the reviewer subject or email from the token, `rejectionReason` string echoing the supplied reason, and `processedAt` ISO-8601 date-time. The suspended JSON-RPC call is cancelled and the agent receives `APPROVAL_DENIED`.
**Errors:**
- 400: `reason` is missing, empty, or whitespace only.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator does not hold the `admin` or `operator` role.
- 404: No approval ticket exists with the supplied identifier.
- 409: The ticket was already resolved by another reviewer; the response identifies the resolving reviewer and the console refreshes the row.
- 409: The agent session was cancelled while the ticket was pending; the ticket is closed and the rejection is recorded without resuming execution.
- 410: The ticket expired before the decision arrived; the suspended call has already failed closed.

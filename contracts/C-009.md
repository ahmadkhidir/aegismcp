# C-009: GET /api/v1/system/status

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header; any RBAC role (`admin`, `operator`, `auditor`, `viewer`) may read the fleet status.
**Request:** No query parameters and no body.
**Response 200:** Object with:
- `status`: string, one of `NORMAL`, `ELEVATED`, `LOCKDOWN`, the fleet threat level.
- `activeConnections`: integer, the number of open agent transport streams.
- `connectedNodes`: integer, the number of gateway nodes currently reporting to the cluster.
- `totalRequests24h`: integer, tool requests intercepted in the last 24 hours.
- `blockedViolations24h`: integer, tool requests blocked in the last 24 hours.
- `pendingApprovals`: integer, approval tickets awaiting a human decision.
**Errors:**
- 401: The access token is missing, expired, or invalid.
- 503: The telemetry store is unreachable, so the counters cannot be read.

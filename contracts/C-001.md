# C-001: POST /mcp/v1/rpc

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Agent workload over mutual TLS presenting a SPIFFE/SPIRE X.509 SVID, or over TLS with an OIDC Bearer JWT issued by the configured enterprise identity provider, carried in the `Authorization` header with the `Bearer` scheme. The verified SPIFFE ID or JWT subject is bound to the session before the request is evaluated.
**Request:** JSON-RPC 2.0 request object over HTTPS.
- `jsonrpc`: string, required, exactly `"2.0"`.
- `id`: string or number, required; the value is returned unchanged on the response.
- `method`: string, required. `tools/call` and `resources/read` are policy-evaluated; other MCP methods pass through to the upstream server.
- `params`: object, optional for transport methods that take none (`initialize` carries client info and capabilities; `tools/list` and `ping` take an empty object). Required for `tools/call`, with `name` string and `arguments` object, and for `resources/read`, with `uri` string. The WebSocket and Stdio transports defined in FEAT-001 carry the same JSON-RPC envelope; this entry fixes the HTTPS route and its status mapping.
**Response 200:** JSON-RPC 2.0 response object. It carries `jsonrpc` set to `"2.0"`, repeats the request `id` unchanged, and carries `result` as the upstream MCP result after outbound DLP inspection. Each detected credential in `result` is replaced with `[REDACTED_SECRET:TYPE]` and each detected personal identifier with `[REDACTED_PII:TYPE]`, where TYPE is the detected family (for example `AWS_KEY`, `GITHUB_TOKEN`, `OPENAI_KEY`, `CREDIT_CARD`, `SSN`). A response above the 20 MB output ceiling is truncated and carries a `RESPONSE_TOO_LARGE` notice. An error response carries `jsonrpc` set to `"2.0"`, repeats the request `id` unchanged, and carries an `error` object with an integer `code`, a `message` string, and a `data` object holding the machine code in `data.code`.
**Errors:**
- 400: The body is not parseable JSON; `error.code` is `-32700` (`Parse error`), machine code `PARSE_ERROR`; nothing is forwarded upstream.
- 400: The body parses but is not a JSON-RPC 2.0 request object because `jsonrpc`, `id`, or `method` is absent; `error.code` is `-32600` (`Invalid Request`), machine code `INVALID_REQUEST`.
- 400: Arguments fail the target tool's published JSON schema; `error.code` is `-32602` (`Invalid params`), machine code `SCHEMA_VALIDATION_FAILED`.
- 401: The SVID or JWT is missing, expired, revoked, or not trusted; `error.code` is `-32000` (`Authentication Failed`), machine code `AUTHENTICATION_FAILED`; no session is established.
- 403: The agent identity has no assigned policy or the requested tool is absent from its policy; `error.code` is `-32001` (`Policy Violation`), machine code `TOOL_NOT_PERMITTED`.
- 403: An argument violates a declared constraint such as a path whitelist, domain allowlist, or maximum row limit; `error.code` is `-32001`, machine code `ARGUMENT_CONSTRAINT_VIOLATED`.
- 403: A path argument resolves outside the permitted root after canonicalization; `error.code` is `-32001`, machine code `PATH_TRAVERSAL`.
- 403: A string argument matches SQL-injection heuristics; `error.code` is `-32001`, machine code `SQL_INJECTION`.
- 403: The tool sequence matches a prohibited private-read-then-egress pattern; `error.code` is `-32001`, machine code `TOOL_CHAIN_BLOCKED`; the session is quarantined.
- 403: A human reviewer rejected the suspended call; `error.code` is `-32002` (`Approval Denied`), machine code `APPROVAL_DENIED`.
- 408: The approval ticket reached its 300-second time-to-live without a decision; `error.code` is `-32002`, machine code `APPROVAL_TIMEOUT`.
- 429: The agent exceeded the invocation velocity threshold of more than 100 tool calls in 10 seconds; `error.code` is `-32003` (`Rate Limited`), machine code `INVOCATION_VELOCITY_EXCEEDED`; the session is paused until an operator resets it.
- 500: An unhandled gateway failure occurred; `error.code` is `-32603` (`Internal error`), machine code `INTERNAL_ERROR`; no stack trace or internal detail is returned.
- 502: The upstream MCP server crashed, disconnected, or did not answer; `error.code` is `-32603`, machine code `UPSTREAM_UNAVAILABLE`; the upstream socket is closed.
- 503: The approval notification path is unavailable and the call could not be queued; `error.code` is `-32002`, machine code `APPROVAL_SERVICE_UNAVAILABLE`.

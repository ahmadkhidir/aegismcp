# C-005: GET /api/v1/policies

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin`, `operator`, or `auditor` role.
**Request:** Optional query parameter `status`, one of `active`, `draft`, `archived`. When omitted, every policy version is returned.
**Response 200:** Object with a `policies` array. Each policy carries:
- `id`: string, the stable policy identifier.
- `name`: string, the descriptive policy title.
- `version`: string, the semantic version of the policy configuration.
- `rawYaml`: string, the complete declarative YAML policy text.
- `status`: string, one of `active`, `draft`, `archived`.
- `gitCommitHash`: string or null, the Git commit that introduced the version.
- `createdAt`: string, ISO-8601 date-time.
**Errors:**
- 400: `status` is present but is not one of `active`, `draft`, `archived`.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds none of the `admin`, `operator`, `auditor` roles.

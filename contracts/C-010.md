# C-010: GET /api/v1/metrics/summary

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header; any RBAC role (`admin`, `operator`, `auditor`, `viewer`) may read the summary counters.
**Request:** No query parameters and no body.
**Response 200:** Object with:
- `activeAgents`: integer, distinct agent identities with an open session.
- `toolCalls24h`: integer, tool calls intercepted in the last 24 hours.
- `blockedViolations24h`: integer, tool calls blocked in the last 24 hours.
- `pendingApprovals`: integer, approval tickets awaiting a human decision.
- `uptimeSeconds`: integer, seconds since the gateway process started.
**Errors:**
- 401: The access token is missing, expired, or invalid.
- 503: The telemetry store is unreachable, so the counters cannot be read.
**Conformance test:** dev.aegismcp.e2e.contracts.C010MetricsSummaryContractTest#reportsTwentyFourHourMetricSummary
**Conformance run:** ./gradlew :tests:e2e:test --tests "*C010MetricsSummaryContractTest"

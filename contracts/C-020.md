# C-020: GET /api/v1/metrics/timeseries

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header; any RBAC role (`admin`, `operator`, `auditor`, `viewer`) may read the chart data.
**Request:** No query parameters and no body. The series always covers the 24 hours ending at the current hour.
**Response 200:** Object with `interval` exactly `HOUR` and a `buckets` array of 24 items ordered oldest first. Each bucket carries `bucketStart` ISO-8601 date-time for the start of the hour, `toolCalls` integer counting tool calls intercepted in that hour, and `blockedViolations` integer counting tool calls blocked in that hour.
**Errors:**
- 401: The access token is missing, expired, or invalid.
- 503: The telemetry store is unreachable, so the series cannot be read.

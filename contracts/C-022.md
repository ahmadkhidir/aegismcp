# C-022: GET /health

**Status:** Frozen
**Owner:** services/gateway
**Auth:** None. The probe is served unauthenticated on the same listener as the agent transports, and its response exposes no tenant, credential, host, path, or exception detail.
**Request:** No query parameters and no body.
**Response 200:** Object with `status` exactly `UP`, returned for as long as the process serves requests. This is the liveness signal and it does not reflect the state of the gateway's dependencies; the readiness probe is `GET /ready` (C-023).
**Errors:**
- 405: The request method is not `GET`. The body is an object with `error` exactly `Method Not Allowed`, and no host, path, or exception detail.
- 500: The probe cannot be answered. The body is an object with `error` exactly `Internal Server Error`, and no host, path, or exception detail.

# C-018: PUT /api/v1/policies/active

**Status:** Draft
**Owner:** services/gateway
**Auth:** Console administrator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` role. When the deployment runs in GitOps-managed mode, direct deployment through this endpoint is disabled.
**Request:** Object with:
- `version`: string, required, the semantic version to activate.
- `rawYaml`: string, required, the complete declarative YAML policy text to activate.
**Response 200:** The newly activated policy version as an object with `id` string, `name` string, `version` string, `rawYaml` string, `status` exactly `active`, `gitCommitHash` string or null, and `createdAt` ISO-8601 date-time. The compiled policy replaces the in-memory cache before the response is returned.
**Errors:**
- 400: The YAML is syntactically invalid, violates the policy schema, or contains an unsupported rule keyword; the previously active policy stays in force.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator does not hold the `admin` role, or the deployment is GitOps-managed and rejects direct deployment.
- 409: Another operator activated a policy version after this client read the active state, so the submitted version no longer matches the current head.

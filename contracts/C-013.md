# C-013: GET /api/v1/audit/records

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Compliance auditor or administrator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin` or `auditor` role.
**Request:** Optional query parameters:
- `agentId`: string, exact agent identity.
- `toolName`: string, exact tool name.
- `decision`: string, one of `allow`, `block`, `require_approval`.
- `blockHash`: string, exact SHA-256 block hash.
- `from`: string, ISO-8601 date-time, inclusive lower bound on `timestamp`.
- `to`: string, ISO-8601 date-time, inclusive upper bound on `timestamp`.
- `limit`: integer from 1 to 500, default 50.
- `offset`: integer of zero or greater, default 0.
**Response 200:** Object with a `records` array and a `total` integer counting all tool-interaction records that match the filters. Records are ordered by `blockIndex` descending. Each record carries:
- `blockIndex`: integer, the sealed block number.
- `blockHash`: string, the SHA-256 hash of the block.
- `parentHash`: string, the SHA-256 hash of the preceding sealed entry.
- `agentId`: string, the agent that initiated the interaction.
- `toolName`: string, the invoked MCP tool.
- `argumentsHash`: string, the SHA-256 digest of the canonicalized request arguments sealed with the decision; the arguments themselves are never stored or returned.
- `decision`: string, one of `allow`, `block`, `require_approval`.
- `redactionCount`: integer, the number of credential or personal-data values masked by DLP.
- `latencyMs`: number, total proxy processing latency in milliseconds.
- `timestamp`: string, ISO-8601 date-time when the block was sealed.
- `reviewedBy`: string or null, the human reviewer for an interaction that required approval, or null when no approval applied.

The query returns tool-interaction blocks only. An administrative action is sealed in the same chain as an administrative audit entry, so consecutive `blockIndex` values in the response may skip the index that entry occupies while every `parentHash` still names the immediately preceding sealed entry of either kind; `total` counts matching tool-interaction records only.
**Errors:**
- 400: `decision` is not one of the declared values, `limit` falls outside 1 to 500, `offset` is negative or not an integer, or a `from` or `to` value is not an ISO-8601 date-time.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds neither the `admin` nor the `auditor` role.
- 503: The ledger store is unreachable, so the records cannot be read.

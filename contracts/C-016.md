# C-016: GET /api/v1/audit/violations

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header; any RBAC role (`admin`, `operator`, `auditor`, `viewer`) may read the violation feed.
**Request:** Optional query parameters:
- `agentId`: string, exact agent identity.
- `violationType`: string, one of `prompt_injection`, `tool_chaining_anomaly`, `schema_violation`, `path_traversal`, `unauthorized_tool`, `rate_limit_exceeded`.
- `severity`: string, one of `low`, `medium`, `high`, `critical`.
- `from`: string, ISO-8601 date-time, inclusive lower bound on `createdAt`.
- `to`: string, ISO-8601 date-time, inclusive upper bound on `createdAt`.
- `limit`: integer from 1 to 100, default 5.
**Response 200:** Object with a `violations` array ordered by `createdAt` descending. Each item carries `id` string, `agentId` string, `violationType` string as declared above, `blockHash` string referencing the sealing audit block, `severity` string as declared above, `details` string with the diagnostic explanation of the blocked payload, and `createdAt` ISO-8601 date-time.
**Errors:**
- 400: `violationType` or `severity` is not one of the declared values, `limit` falls outside 1 to 100, or a `from` or `to` value is not an ISO-8601 date-time.
- 401: The access token is missing, expired, or invalid.

# C-019: GET /api/v1/approvals

**Status:** Frozen
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider with an OIDC access token in the `Authorization` header, holding the `admin`, `operator`, or `auditor` role.
**Request:** Query parameters:
- `status`: string, required, one of `approved`, `rejected`, `expired`, selecting the historical tab.
- `limit`: integer from 1 to 100, default 50.
- `offset`: integer of zero or greater, default 0.
**Response 200:** Object with a `tickets` array ordered by the resolution time descending, and a `total` integer counting all tickets that match `status`. Each ticket carries `id` string, `agentId` string, `toolName` string, `argumentsPayload` string holding the JSON-serialized request arguments with secret values already masked, `status` string as declared above, `triggerPolicyId` string, `createdAt` ISO-8601 date-time, `expiresAt` ISO-8601 date-time, `reviewedBy` string or null, `rejectionReason` string or null, and `processedAt` string or null holding the time the ticket was resolved — the human decision time for an approved or rejected ticket, the expiry time for an expired one, and null only while a ticket is pending.
**Errors:**
- 400: `status` is missing or not one of the declared values, `limit` falls outside 1 to 100, or `offset` is negative or not an integer.
- 401: The access token is missing, expired, or invalid.
- 403: The authenticated operator holds none of the `admin`, `operator`, `auditor` roles.

# C-002: GET /api/v1/stream/traffic

**Status:** Draft
**Owner:** services/gateway
**Auth:** Console operator authenticated through the enterprise identity provider. The request carries either the OIDC access token in the `Authorization` header with the `Bearer` scheme, for a fetch-based event reader, or the console session cookie issued at login, for a browser-native `EventSource` connection. Any RBAC role (`admin`, `operator`, `auditor`, `viewer`) may subscribe; the stream is read-only.
**Request:** No query parameters and no body. Inspector filters (agent identity, decision, tool name, latency range) are applied client-side over the received stream.
**Response 200:** Server-sent event stream with `Content-Type: text/event-stream` and `Cache-Control: no-cache`. The stream opens with `retry: 3000`. Three named event types are emitted:
- `traffic`: one event per intercepted `tools/call`. `data` is a JSON object with `eventId` string, `timestamp` ISO-8601 date-time, `agentId` string, `toolName` string, `arguments` object holding the intercepted request arguments, `decision` one of `ALLOWED`, `BLOCKED`, `PENDING_APPROVAL`, `latencyMs` number, `matchedRuleIds` array of strings, and `redactions` array of objects with `category` one of `SECRET`, `PII`, `type` string, and `count` integer.
- `approval`: one event when an approval ticket is created, approved, rejected, or expired. `data` is a JSON object with `ticketId` string, `status` one of `pending`, `approved`, `rejected`, `expired`, and `expiresAt` ISO-8601 date-time.
- `system`: one event when the fleet threat level or pending approval count changes. `data` is a JSON object with `status` one of `NORMAL`, `ELEVATED`, `LOCKDOWN`, and `pendingApprovals` integer.
Every event carries an `id` field with a value that increases monotonically for the life of the gateway node. A `: keepalive` comment is written every 15 seconds while the stream is idle. On disconnect the client reconnects with exponential backoff starting at 1 second and capping at 30 seconds, without reloading the page; events produced during the gap are not replayed, and the console re-fetches the pending queue through C-003 after reconnect.
**Errors:**
- 401: The access token or session cookie is missing, expired, or invalid; no stream is opened.
- 403: The authenticated operator holds no console role; access is refused and the attempt is logged.
- 503: The telemetry broadcaster is unavailable or the gateway is draining; the stream is refused so the console can show its reconnect state.
